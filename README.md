# ⚽ World Cup Soccer — Claude World Cup

브라우저에서 즉시 플레이하는 **3D 월드컵 축구 시뮬레이션 게임**입니다.
**Three.js(WebGL)** 기반 실사형 3D 엔진(원근 카메라·조명·그림자·스타디움) 위에,
32개국 본선 · 조별리그 · 16강 토너먼트를 얹었습니다. 빌드 도구 없이 정적 파일로만 동작합니다.

## 🎮 플레이 방법

- **월드컵 모드** — 국가대표를 골라 조별리그부터 결승까지. 내 경기는 직접 플레이하고, 나머지 경기는 전력 기반으로 시뮬레이션됩니다.
- **빠른 경기** — 랜덤 상대와 1경기 바로 즐기기.

### 조작 (롤 방식 클릭 이동)
| 동작 | 조작 |
|------|------|
| 이동 | 경기장을 **마우스 클릭 / 터치** → 그 위치로 이동 |
| 패스 | `J` 키 또는 A 버튼 (열린 동료에게) |
| 슛 / 클리어 | `K` 키 또는 B 버튼 (길게 누르면 강하게) |

공에서 멀면 자동으로 가장 가까운 선수를 조작합니다. 전·후반 각 90초.

### 지능 AI
- **프레싱** — 볼에 가장 가까운 1명만 압박, 나머지는 형태 유지
- **맨마킹** — 수비수가 위협적인 상대를 골사이드에서 마크
- **오프더볼 런** — 공격 시 폭을 벌리고 전방으로 침투
- **패스 길목 판단** — 상대가 막은 패스 경로는 회피
- 유니폼 색이 겹치면 어웨이 팀이 자동으로 대체 키트 착용

## 🗂 구조
```
index.html        화면 마크업
css/style.css     스타일
js/lib/three.min.js  Three.js (WebGL 3D 라이브러리, 로컬 번들)
js/teams.js       32개국 데이터
js/match.js       3D 축구 엔진 (물리·지능 AI·Three.js 렌더)
js/tournament.js  조별리그/토너먼트 로직
js/main.js        화면 전환·UI 흐름
```

## 🚀 배포
`main` 또는 개발 브랜치에 푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
로컬 실행은 정적 서버면 충분합니다:
```bash
python3 -m http.server 8000
# http://localhost:8000
```
