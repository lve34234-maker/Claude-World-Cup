# ⚽ World Cup Soccer — Claude World Cup

브라우저에서 즉시 플레이하는 **월드컵 축구 시뮬레이션 게임**입니다.
HTML5 Canvas로 구현된 탑다운 아케이드 축구 엔진 위에, 32개국 본선 ·
조별리그 · 16강 토너먼트를 얹었습니다. 빌드 도구 없이 정적 파일로만 동작합니다.

## 🎮 플레이 방법

- **월드컵 모드** — 국가대표를 골라 조별리그부터 결승까지. 내 경기는 직접 플레이하고, 나머지 경기는 전력 기반으로 시뮬레이션됩니다.
- **빠른 경기** — 랜덤 상대와 1경기 바로 즐기기.

### 조작
| 동작 | 키보드 | 모바일 |
|------|--------|--------|
| 이동 | 방향키 / WASD | 화면 D-패드 |
| 패스 | `J` | A 버튼 |
| 슛 / 클리어 | `K` (길게=강하게) | B 버튼 |

공에서 멀면 자동으로 가장 가까운 선수를 조작합니다. 전·후반 각 90초.

## 🗂 구조
```
index.html        화면 마크업
css/style.css     스타일
js/teams.js       32개국 데이터
js/match.js       Canvas 축구 엔진 (물리·AI·렌더)
js/tournament.js  조별리그/토너먼트 로직
js/main.js        화면 전환·UI 흐름
```

## 🚀 배포
`main` 또는 개발 브랜치에 푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
로컬 실행은 정적 서버면 충분합니다:
```bash
python3 -m http.server 8000
# http://localhost:8000
```
